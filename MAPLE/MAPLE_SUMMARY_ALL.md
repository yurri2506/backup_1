## Số liệu thống kê được

### Thông tin thu thập
- **Tổng số runs:** 80 runs (10 runs cho mỗi N: 1, 10, 20, 50, 100, 200, 500, 700)
- **Nguồn dữ liệu:** Log files từ `/usr/bin/time -v` trong thư mục `logs/MAPLE/`
- **File pattern:** `proof_ppgen_sabv_lmtr5_MAPLE_{N}_{run_id}.no_input.log` (hoặc `proof_ppgen_sabv_lmtr5_v5_{N}_{run_id}.no_input.log` cho các runs cũ)
- **Metrics thu thập:**
  - Elapsed (wall clock) time
  - CPU usage (%)
  - Maximum resident set size (RAM - GB)
  - User time (seconds)
  - System time (seconds)
  - Proof size (MB) - nếu có

### Phương pháp thống kê
- **Trung bình (Mean):** Giá trị trung bình của tất cả runs
- **Min/Max:** Giá trị nhỏ nhất và lớn nhất
- **CV (Coefficient of Variation):** Độ biến thiên = (Std Dev / Mean) × 100%

### Trạng thái runs
- ✅ Tất cả 80/80 runs đã hoàn thành (100%)
- ✅ Không có runs thiếu metrics (sau khi loại bỏ runs đang chạy)
- ⚠️ 12/80 runs có số liệu bất thường (do kẹt RAM/resource contention)

## Script chạy chính

### Binary chính
- **Package:** `pessimistic-proof-test-suite`
- **Binary:** `ppgen_sabv_lmtr5`
- **Thư mục:** `/home/ubuntu/backup_1/agglayer`

### Scripts execution

#### 1. Script chạy đủ 10 runs cho mỗi N
- **File:** `run_v5_fill_missing_10runs.sh` (file thực tế vẫn dùng tên cũ)
- **Mục đích:** Chạy đủ 10 runs cho mỗi N (1, 10, 20, 50, 100, 200, 500, 700)
- **Cách chạy:** 
  ```bash
  cd /home/ubuntu/backup_1
  bash run_v5_fill_missing_10runs.sh
  ```
- **Chạy trong:** tmux session `baseline_ppgen_v5_fill_10runs` (session name vẫn dùng tên cũ)
- **Log files:**
  - `logs/MAPLE/fill_10runs.log`
  - `logs/MAPLE/fill_10runs_console.log`
  - `logs/MAPLE/dstat_fill_10runs.log`

#### 2. Script chạy trong tmux (quản lý đầy đủ)
- **File:** `baseline_v5_tmx.sh` (file thực tế vẫn dùng tên cũ)
- **Mục đích:** Chạy các rounds với monitoring đầy đủ (dstat, stress-ng, SP1 server)
- **Tmux session:** `baseline_ppgen_v5` (session name vẫn dùng tên cũ)

#### 3. Script chạy thêm runs (topup)
- **File:** `run_v5_topup.sh` (file thực tế vẫn dùng tên cũ)
- **Mục đích:** Chạy thêm runs cho các N còn thiếu

### Command line chính
```bash
cd /home/ubuntu/backup_1/agglayer

export SP1_PROVER="cpu"
export RAYON_NUM_THREADS=32
export OMP_NUM_THREADS=32
export SP1_CORE_OPTS_TRACE_GEN_WORKERS=8
ulimit -v unlimited

/usr/bin/time -v cargo run --release -p pessimistic-proof-test-suite --bin ppgen_sabv_lmtr5 -- \
  --n-exits {N} \
  --validator-nodes 5 \
  --proof-dir /home/ubuntu/backup_1/logs/MAPLE/proofs \
  --run-label {run_id}
```

### Environment variables
- `SP1_PROVER=cpu`: Sử dụng CPU-based proving
- `RAYON_NUM_THREADS=32`: Số threads cho Rayon parallel processing
- `OMP_NUM_THREADS=32`: Số threads cho OpenMP
- `SP1_CORE_OPTS_TRACE_GEN_WORKERS=8`: Số workers cho SP1 trace generation

### Scripts phân tích
- `statistics_MAPLE_all_runs.py`: Thống kê toàn bộ runs
- `statistics_MAPLE_detailed.py`: Thống kê chi tiết (format tương tự baseline)
- `statistics_MAPLE_good_runs_only.py`: Thống kê chỉ runs tốt
- `statistics_MAPLE_better_than_avg.py`: Thống kê runs nhỏ hơn trung bình
- `analyze_MAPLE_outliers.py`: Phân tích runs bất thường
